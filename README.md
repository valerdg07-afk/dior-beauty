# Dior Beauty - Sitio Web Mockup

¡Bienvenido al repositorio de **Dior Beauty**! Este proyecto es un mockup web profesional inspirado en la elegancia y estética de la marca de lujo Dior. Está diseñado utilizando prácticas modernas de desarrollo web, asegurando una experiencia visual atractiva y responsiva.

---

## 💻 Tecnologías Utilizadas

* **HTML5:** Estructuración semántica de todas las secciones.
* **CSS3:** Estilos personalizados, tipografías elegantes y diseño adaptativo (Responsive Design).

---

## 📂 Estructura del Proyecto

El sitio web está organizado de la siguiente manera:

* `index.html` - Página de inicio (Home) con la presentación principal de la marca.
* `nosotros.html` - Información sobre la historia, visión y valores de Dior.
* `servicios.html` - Detalle de los servicios exclusivos o experiencias ofrecidas.
* `galeria.html` - Exhibición visual de productos destacados y colecciones de belleza.
* `contacto.html` - Formulario de contacto e información de ubicación.
* `estilos.css` - Hoja de estilos centralizada para todo el diseño del sitio.
* `img/` - Carpeta que contiene los recursos visuales y fotografías del proyecto.

---

## 🚀 Características

* **Diseño Elegante:** Inspirado directamente en la paleta de colores y tipografía de alta costura.
* **Navegación Intuitiva:** Menú estructurado para moverse fácilmente entre las 5 páginas estáticas.
* **Layout Responsivo:** Optimizado para visualizarse correctamente tanto en computadoras de escritorio como en dispositivos móviles.

---

## 🛠️ Cómo Visualizar el Proyecto

1. Clona este repositorio o descarga los archivos en tu computadora.
2. Abre la carpeta del proyecto.
3. Haz doble clic en el archivo `index.html` para abrirlo en tu navegador web preferido.
